## 2. 评测容差 ε

**ε = 1.0%**（相对误差）。敏感性三档 {0.5%, 1.0%, 2.0%}。

依据：TASK-01 的 |Δ| 分布在口径对齐条目上呈双峰——68/95 精确相等，25 条落在 0.0001%–0.90%，两个离群点在 1.62% 与 3.15%。最大自然间隙 **0.90% → 1.62%**（0.717 个百分点），ε=1.0% 落在谷底。**非惯例取值。**

**四舍五入分支：** 叙事数字位数少于申报值时，若申报值落在叙事数字的四舍五入区间内，判 SUPPORTED。该分支与相对容差**并列**，不从属（歧义 #15）。

**构造容差与评测容差是两个独立常量**（INV-1）。构造侧见 §3，其判定为精确相等，不使用 ε。

## 3. 自证锚点四条件（INV-11，不得放宽）

一个 `(company, metric, page, span)` 四元组被接受为自证锚点，当且仅当：

| 条件 | 阈值 | 作用 |
|---|---|---|
| **C1** 单位归一后全部有效数字相等 | 精确，容差 0 | 排除「近似相符」的巧合 |
| **C2** 有效数字位数 | ≥ 4 | 防伪匹配的主力 |
| **C3** 非圆整数 | 排除 10^k 与 {1,2,5}×10^k | 排除年份、页码、目标值 |
| **C4** 落在该指标词法锚点窗口内 | ±200 字符 | 排除跨主题巧合 |

**C1 与 C2 为何是关键：** D0 报告的反例——台泥範疇二申报 1,536,737 与营业收入净额 154,606,511×0.01 相差 0.6%——在 C1 下直接出局，因为它不是精确相等。TASK-01 进一步实证了 C2/C3 的必要性：ISO **14001** 曾匹配火灾死伤 14 人、ISO **22301** 匹配范畴三、GRI **301** 匹配火灾件数、EN **1015** 匹配薪资平均数、IPCC **2006** 与年份 **2025** 匹配吨数。这些全部是 ≤4 位或圆整数。

任何为提高产出量而放宽四条件之一的改动，都必须重新计算伪匹配率上界。

### 3.1 量纲集

`[1, 10, 0.1, 1e2, 1e-2, 1e3, 1e-3, 1e4, 1e-4, 1e8, 1e-8]`

台湾报告惯用 **萬(1e4)** 与 **億(1e8)**；**萬元 → 仟元 为 ×10**。省略这三者会整批漏掉以「萬元」表述的薪资条目（TASK-01 在华航实证）。

### 3.2 词法锚点表

见 `config/anchor_rules.json`。歧义 #11 实证的三条补入：

| 指标 | 补入 |
|---|---|
| `water_intensity` | 單位鋼胚用水量、單位產品用水量、人均用水量 |
| `waste_intensity` | 人均廢棄物量、單位產品廢棄物 |
| `nonmgr_salary_avg` | 非擔任主管職之平均薪資、非管理階層之全職人員薪資平均數 |

## 4. 扰动配比

`config/perturbation_mix.json`。合计 100%。seed 20260914（INV-6）。

| 扰动 | 配比 | gold |
|---|---:|---|
| P-none（控制组） | 25% | SUPPORTED |
| P-magnitude | 20% | δ ≤ ε → SUPPORTED；δ > ε → CONTRADICTED |
| P-consolidation | 15% | NOT_COMPARABLE |
| P-intensity | 11% | NOT_COMPARABLE |
| P-scope | 9% | NOT_COMPARABLE |
| P-unit | 6% | CONTRADICTED |
| P-null | 5% | NOT_APPLICABLE |
| P-crosscompany（负控） | 5% | NOT_COMPARABLE |
| P-indistinct | 4% | NOT_COMPARABLE |

**口径类四种按实测比例注入，非四类均分。** TASK-01 实测 21 条 NOT_COMPARABLE 的成因：consolidation 8、absolute_vs_intensity 6、scope 5、indistinguishable 2。折算后与配比的偏差 ≤ 0.008。

**P-magnitude 的 δ 网格：** ±{0.1, 0.3, 0.6, 0.9, 1.2, 2, 5, 15}%。跨 ε=1.0% 边界两侧各有档位，用于画有效容差曲线（Fig.6）。

**P-crosscompany 是健全性地板。** 任何系统低于 0.90 即说明评测管线有缺陷，须先排障。

## 7. 构造效度三项（替代 Cohen's κ）

| 指标 | 目标 |
|---|---|
| 伪匹配率上界（组合论证，参数须实测填入） | < 0.01 |
| 冗余印证率（同一数值独立出现于第二处且词法环境一致） | 报告实测值 |
| 负控通过率（跨公司配对被 C1–C4 拒绝） | > 0.99 |

三项合计构成论文 §4 的效度地基。**§4 是全文最重要的一节**——构造效度取代了 IAA，论证不扎实则地基是空的。
